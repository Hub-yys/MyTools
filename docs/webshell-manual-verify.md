# 真机验证清单（WebShell / P4 定稿前）

> **给谁用**：能开着游戏、能以管理员权限启动本程序的人。
>
> **为什么需要**：自动化验证（123 项）只能证明「代码逻辑对」，
> 证明不了「真的能操作游戏」。本轮自动化跑在我的机器上，
> **游戏没开**，所以 4 个 ok-ww 工具全部停在 `start_failed`。
> 真实的状态流转（`booting → running → done`）只验证了前半段。
>
> **怎么用**：照着勾。每行都有「预期」，不符合预期就在结果栏写 ❌
> 并记下实际现象 —— 那才是最有价值的信息。

## 已知的、不算 bug 的现象

**看到这些不用报 bug** —— 它们是正常行为：

| 现象 | 为什么 |
|---|---|
| 首次启动慢（5~20 秒）才进入可运行状态 | ok-ww 引擎在 boot，`state=booting`。页面会显示「引擎启动中」，**不会误判成已完成** |
| 显示「引擎已就绪但任务没进入运行」（`mayNotRun`） | 游戏没开 / 界面不在正确位置 / 没管理员权限。照提示逐条排查 |
| `RuntimeError: 游戏画面比例是 1800:1055（1.71），不是 16:9（1.78）` | 游戏窗口不是 16:9。**这不是 bug**，是硬校验（点击位置按 16:9 比例定的） |
| 点了运行没反应，日志有「点击会被静默丢弃」 | 没以管理员身份运行 |
| 声骸强化报「没有勾选任何残像聚落」 | 扫荡勾选是空的（先去 ④ 勾几个） |
| 关闭窗口时弹确认框 | **正常**，防止误关（和旧界面一致） |
